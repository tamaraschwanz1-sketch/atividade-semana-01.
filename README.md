# HERO<span>VERSE</span> — Marvel & DC

Atividade Prática — Semana 01

## Descrição
Aplicação web desenvolvida com Node.js e Express,
com interface moderna e responsiva inspirada nos
universos Marvel e DC.

## Tecnologias
- Node.js
- Express.js
- HTML5
- CSS3

## Rotas
- / — Página inicial
- /marvel — Universo Marvel
- /dc — Universo DC

## Como executar
1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute: npm install
4. Execute: npm start
5. Acesse: http://localhost:3000

## Objetivo
Demonstrar conhecimentos básicos de criação
de servidores e roteamento HTTP com Express.
